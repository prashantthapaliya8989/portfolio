Enhanced Emergency Notification System - Everbridge and AGOL Integration

Python, ArcPy, GeoPandas, Everbridge API, ArcGIS REST API

Problem

During active incidents (e.g., wildfires, flood or police activity), public evacuation zones were manually drawn in Everbridge but were not visible on public maps in real time. The polygons along with their metadata had to be exported from Everbridge, converted manually, and uploaded to Google Maps, delaying situational awareness for the public, first responders and decision makers.


Solution

Built an automated sync service that runs every 2 minutes, pulling real-time incident data (including polygons and attachments) from Everbridge's API and pushing them directly into a hosted ArcGIS Online Feature Layer. These updates power a public-facing dashboard that visualizes evacuation zones and incident details in near real-time.

Features

  • Real-Time Sync: Runs on a schedule to fetch the latest notifications and polygon geometries.
  • Geometry Management:
    • Automatically fills missing geometries from previous entries.
    • Detects overlapping polygons and deactivates outdated zones based on percent overlap.
    • Cuts out overlapping zones and keeps only the largest remaining geometry.
  • Attachment Support: Downloads and links images from Everbridge.
  • Logging with Email Alerts: Custom logging with SMTP alerts on failures.
  • Interactive Dashboard Integration: Powers a public-facing ArcGIS Dashboard for real-time situational awareness.

Impact

  • Reduced update time: Can enable faster public awareness.
  • Eliminated manual GIS processing: Can free up user time during emergencies.
  • Improved map accuracy: Public maps can include attachments and precise boundaries.
  • Enhanced decision-making: Automated spatial storytelling can support real-time emergency response.
