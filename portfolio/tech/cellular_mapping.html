📡 Cellular Sector Mapping Toolbox for ArcGIS Pro

Pandas, Math, Arcpy, Point, PointGeometry, Array, Polygon

Problem

Accurate and up-to-date information on cell sites is essential for effective public safety planning, establishing emergency communication zones, and supporting incident response efforts. However, ArcGIS Pro lacked a built-in tool that addressed specific operational requirements or supported automated imports of cellular data.


Solution

Developed a custom Python toolbox (.pyt) for ArcGIS Pro that automates the import, processing, and visualization of cell tower locations and their signal coverage areas. Maintaining accurate and up-to-date cellular coverage information is critical for planning public safety infrastructure, emergency communication zones, and incident response coordination. This tool:

  • Reads updated or new cellular tower data from a standardized CSV file.
  • Creates cell site point features and wedge-shaped sector polygons representing coverage areas based on azimuth, beamwidth, and radius.
  • Projects all geometries from WGS84 (latitude/longitude) to the spatial reference of geodatabase.
  • Automatically determines the compass direction (e.g., N, NE, S) for each sector using azimuth logic.
  • Connects to geodatabase feature classes and performs clean insertions by removing existing matching records to prevent duplicates.
  • Uses pandas for efficient CSV parsing and arcpy.da cursors for high-performance editing of spatial data.
This tool is packaged for easy use in ArcGIS Pro and is designed to support batch updates from carriers or field reports.
